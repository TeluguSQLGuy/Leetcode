## 📚 నేర్చుకోబోయే SQL Topics

| Topic | ఏమి నేర్చుకుంటాం? |
|---|---|
| `SELECT` & `WHERE` | అవసరమైన Data‌ను Retrieve చేయడం, Conditions ఆధారంగా Filter చేయడం |
| Aggregate Functions | `SUM()`, `AVG()`, `COUNT()`, `MIN()`, `MAX()` ఉపయోగించడం |
| `GROUP BY` & `HAVING` | Data‌ను Groups‌గా విభజించడం, Aggregated Results‌ను Filter చేయడం |
| `JOIN` | Multiple Tables నుంచి Data‌ను Combine చేయడం |
| Subqueries | ఒక Queryలో మరో Query రాయడం |
| `CASE` Statement | Conditions ఆధారంగా Results‌ను పొందడం |
| Window Functions | `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()` ఉపయోగించడం |
| Date & String Functions | Dates మరియు Strings‌పై Operations చేయడం |

*Repositoryలో Solutions పెరుగుతున్న కొద్దీ మరిన్ని Topics చేర్చబడతాయి.*

## 🚀 ఈ Repositoryని ఎలా ఉపయోగించాలి?

1. Repositoryలో ఉన్న ఒక Problem‌ను ఎంచుకోండి.
2. ముందుగా Problem Statement‌ను పూర్తిగా అర్థం చేసుకోండి.
3. Solution చూడకముందే మీరే SQL Query రాయడానికి ప్రయత్నించండి.
4. Queryని Run చేసి Output‌ను Verify చేయండి.
5. Query ఎలా పనిచేస్తుందో, అందులో ఉపయోగించిన Logic ఏమిటో అర్థం చేసుకోండి.
6. కొంత సమయం తర్వాత అదే Problem‌ను మళ్లీ Solve చేసి మీ Improvement‌ను పరీక్షించుకోండి.

💡 **చిన్న సూచన:** Solution‌ను వెంటనే చూడకుండా, ముందుగా మీరే ప్రయత్నించండి. ఇలా చేయడం వల్ల మీ SQL Logic మరియు Problem-Solving Skills మెరుగుపడతాయి.
